# Comparison Table Template

Copy this skeleton once per structural dimension identified in Step 1 of `SKILL.md`. Fill one row
per exemplar. Leave a cell as `—` (with a one-line reason) when a dimension does not apply to that
exemplar rather than leaving it blank.

## Per-dimension table

| Exemplar | Sub-feature A (where + how) | Sub-feature B (where + how) | Sub-feature C (where + how) | Notable quotation (located) |
|---|---|---|---|---|
| `<slug-1>` | ¶2: <mechanism>, p.<n> | ... | ... | "<short phrase>" — p.<n> |
| `<slug-2>` | — (no such move; see note) | ... | ... | ... |

## Field-level guidance

- **"Where"** should be as precise as the source allows: paragraph number within a section is more
  useful than "in the introduction somewhere." If the exemplar has printed page numbers, include
  them; if not, say so rather than inventing one.
- **"How"** should describe the actual mechanism in a clause or sentence, phrased so a second reader
  could relocate the same passage without the quotation. Avoid restating the dimension name back
  ("does the intro thing") — say what specifically happens.
- **Quotations** should be short (a phrase to one sentence), never a full paragraph, and always
  carry a locator. Their job in the final report is to anchor a governing-pattern finding to the
  exemplar's own words, not to reproduce content.
- **Absences** are findings, not blanks. If an exemplar skips a dimension entirely, record that and
  — where it can be determined from the reading — a one-line hypothesis for why (space constraint,
  sub-genre convention, different structural job performed by a different section instead).

## Reconciliation worksheet

After the table is filled for a dimension, answer these four questions before writing the
governing-pattern finding (Step 5 of `SKILL.md`):

1. **Does every exemplar agree?** If yes, this is a candidate universal invariant — state it plainly
   and note that it held across the full diversity of sub-genres/venues in the exemplar set.
2. **Do exemplars split along a visible line?** (sub-genre, venue, formality, length constraint) If
   yes, state the pattern as conditional on that line, not as a general rule with exceptions.
3. **Is there exactly one exemplar exhibiting a feature no other exemplar has?** Name it as a
   single-exemplar precedent explicitly — useful as an option, not as evidence of a norm.
4. **What is the underlying mechanism, not just the surface convention?** Restate the finding one
   level more abstractly if doing so makes it apply even to exemplars that satisfy it through a
   different surface form (e.g., a bullet list and a "First/Second/Third" prose paragraph can both
   satisfy the same underlying mechanism: "contributions enumerated exactly once, in one place").
